# Escuela Santaló 2027 — Análisis Funcional

Sitio web de la Escuela Santaló 2027 (26 al 30 de julio de 2027, Universidad de Buenos Aires).

Es un sitio estático (HTML + CSS), pensado para publicarse con GitHub Pages.

## Estructura

- `index.html` — página de inicio
- `conferencias.html`, `cronograma.html`, `abstracts.html`, `registro.html`, `info-local.html` — secciones (por ahora "En construcción")
- `assets/estilo.css` — estilos compartidos
- `assets/fondo.png` — imagen de fondo de la portada
